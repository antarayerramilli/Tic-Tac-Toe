# Cyber Tic-Tac-Toe

## About

A cyber-themed Tic-Tac-Toe game created for VOSC Activity-1 using HTML, CSS and JavaScript.

## Features

- Classic Tic-Tac-Toe gameplay
- Player vs Player mode
- Player vs Computer mode
- Score tracking
- Winning-cell highlighting
- System activity log
- Responsive design
- Cyber-themed interface

## Technologies

HTML5  
CSS3  
Vanilla JavaScript  

## How to Run

Simply open index.html in a web browser.

No installation or dependencies are required.

## How to Play

1. Choose Friend or Computer mode.
2. Choose your side.
3. Take turns selecting cells.
4. Get three symbols in a row to win.
5. Start a new round or reset the score.

## Project Structure

```text
index.html    - Markup and game layout structure
style.css     - Custom cyber-terminal styling and responsive design
script.js     - Game logic, AI decision-making, and event handling
README.md     - Documentation and project overview
```
